# x20ctl 3.0.0

The desktop studio is now a complete metallic-grey native Windows application.

## Added

- Metallic-grey studio shell with silver bevels, cyan state lighting and persistent read/apply controls.
- Saved-setup library, connection discovery, curve guide, help surfaces and themed confirmation dialogs.
- Focus trapping, Escape handling and focus restoration for native dialogs.
- Native-window acceptance coverage for all seven pages, minimum-window layouts, persistence, cancellation and tray behavior.

## Changed

- Rebuilt the controller drawing, button assignment inspector, curves, deadzones, live meters, M1-M4 macro editor, vibration, power, input tester and connection screens.
- Kept device operations native, category-scoped and explicit about unavailable hardware data.
- Replaced the old synthetic screenshot set with direct captures from the packaged executable.

## Fixed

- Unavailable gameplay input is distinct from a connected neutral reading.
- Dialog controls are keyboard-safe and no longer accidentally edit controls behind a modal.
- Expanded smoke coverage catches layout, persistence and cancellation regressions.

## Removed

- Four unused synthetic JPG interface mockups under `src/assets/images`.
- Unsupported or invented telemetry and fake screenshot claims.

## Verification

- Packaged `x20ctl.exe` exited with code 0 and passed 23 native-window checks.
- 503 Python tests, 170 focused tests, frontend tests, lint and production build passed.
- SHA-256: `672175AA2BC88D109795362912C7AF0518F2E59A68AF907E24E1A598852F491F`.

The fresh packaged run had no connected BLE or XInput device, so no physical hardware write or macro playback is claimed for this release.
