# x20ctl 3.1.0

This is a local Windows desktop app, not a hosted website. Download `x20ctl.exe` and run it. The EXE includes Python and the interface, but needs the installed Microsoft WebView2 Runtime. If it is missing, x20ctl offers Microsoft's official download page and Retry; it never installs software silently.

## Added

- Controllers entry page with distinct EasySMX X20 and X20 Pro workspaces.
- X20 Pro front/rear SVG illustration, clearly marked as an illustration rather than live hardware data.
- Read-only Pro investigation tools for BLE advertisements, standard GATT information and Windows HID inventory.
- Separate Pro state and setup-store location. Pro profile import and settings remain locked until hardware verification.
- Four metallic themes, an advanced local color editor with contrast checks, motion controls and reduced-motion support.
- Native-window tests for both models, themes, minimum layouts and model isolation.

## Changed

- Removed the private WebView2 copy. The one-file EXE is 22,183,651 bytes (21.16 MiB), down from 332,176,864 bytes (316.79 MiB) in 3.0.0.
- XInput polling stops outside live-input views and when X20 is hidden. Unchanged samples avoid unnecessary redraws.
- Existing X20 profiles keep their location and schema.

## Fixed

- Switching to Pro disconnects the X20 configuration link and blocks X20 profile, import, read and write API operations until X20 is selected again.
- Theme accent reaches the controller drawing and principal live controls.
- Startup offers a clear recovery path when WebView2 is absent.

## Removed

- Bundled fixed-version WebView2 fallback and its old build/startup flags.

## Verification and limits

The final packaged EXE passed 27 native-window checks and generated 28 direct captures from the running renderer. Focused Python tests: 173 passed, 1 skipped. Frontend type-check, tests and production build passed. On this PC, one initial-screen comparison measured 10.12 to 2.30 seconds to visible window and 1.172 to 0.266 process CPU seconds over 10 idle seconds versus 3.0.0. These are local observations, not universal benchmarks. The missing-runtime path was unit-tested with mocked detection, not by uninstalling WebView2.

No X20 or X20 Pro was connected during the packaged 3.1.0 run. No Pro configuration protocol, GIF upload, display write, motor write or macro upload is claimed. Pro settings stay **Coming soon** until a physical controller provides repeatable, device-specific evidence. No bootloader or firmware operation is included.
