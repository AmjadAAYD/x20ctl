   Extract All. Open the extracted folder and read "1_READ_ME_FIRST.txt".
   Then double-click "2_RUN_ME" and follow the window.
   It only reads basic controller information; it does not change settings.
   If anything is unclear or blocked, stop and tell me the step/message.
   When finished, "3_SEND_THE_RESULT.txt" tells you which file to send back.

   whole research library or ask for extra tools in the first message.

4. Keep "X20ctl-Maintainer-Kit.zip" for you and Codex. It contains the
   source, checksums, validator, advanced instructions and detailed research.

5. After reviewing the first result, give the volunteer ONE next task.
   Explain the exact action and the exact file to send. A failed discovery
   can be useful too. Do not assume the model is supported because it appears.
