X20CTL CONTROLLER KIT - START HERE

This helps Amjad collect information about your EasySMX controller.
Use a Windows 10 or 11 computer. No Python or programming knowledge is needed.

1. Right-click this ZIP and choose "Extract All". Open the extracted folder.
2. Close games, Steam and any controller settings app.
3. Double-click START_HERE.bat (Windows may show just START_HERE).
4. Follow the text window. Type a listed number to choose an option.
   Type y for yes. Press ENTER when you have done the physical instruction.
   Choose 1 for the full scan, or 2 to capture another app setting later.

The window guides you through:
- Your controller model and app/version information you already know.
- Unplugging and reconnecting the controller to identify it.
- Device information and available USB details.
- Buttons, sticks, triggers and any extra buttons you name.
- Optional detailed input and Bluetooth checks.
- Other connections or modes you already know how to use.
- Optional capture of ONE reversible setting in an app you already use.
- Notes, a short review, and saving your result ZIP.

Unknown answer? Press ENTER. Missing button? Type s to skip that check.
To end the current button round, type q. CTRL+C stops the whole collection.
Some stages are optional or may fail; the result records this for Amjad.
Normal and detailed input use separate rounds, so some checks may repeat.

When the tool says DONE, open the "results" folder next to START_HERE.
Send the new ZIP named "scan-..." to Amjad privately in your existing chat.
If you ran several times, use the newest ZIP. Send the actual file, not only
a screenshot. Add your controller model and which connection you tested.
If you stopped early or something looks private, ask Amjad before sending.

The tool reads information; it does not send controller settings or firmware.
In the optional app stage, YOU change one ordinary setting in your normal app
and restore it. The kit records when you do each action.
Nothing is uploaded automatically. Optional detailed input can contain
device-specific data and needs your permission. Review before sharing.
If Windows blocks the tool or you get stuck, stop and tell Amjad the exact
message. Do not disable antivirus, install drivers or guess button combinations.

ControllerScanKit.exe remains available for direct use. The technical folder
keeps the source, build information, checksums and required legal notices.
You do not need to read that folder to complete the guided collection.

APP CAPTURE (optional; skip if you get stuck)
The wizard tells you what to click. Android records Bluetooth through the
phone's HCI snoop option. Windows USB capture uses Wireshark with USBPcap
already installed; the kit does not install drivers. Both recordings are
started/stopped by you. The kit guides the experiment and attaches your file.
For Android, it can read a single full Bluetooth log from a phone bug-report
ZIP without including the full bug report. Some phones do not provide that
log; the timeline is still saved and you can ask Amjad for help.
Raw app captures are NOT anonymized. They can include device IDs or unrelated
traffic. Include them only for private review, and do not share them publicly.
Use a short recording under 4 MB. To test another setting, run START_HERE
again and choose 2. Do not test firmware, factory reset or calibration.
Original HID report descriptors are not requested automatically. A USB trace
may contain descriptor exchanges; Amjad must verify what is actually present.
The kit is a research build; real-controller testing is still pending.
