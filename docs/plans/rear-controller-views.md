# Rear controller views

Scope: six existing models, new rear photographs with the established blue-left
and amber-right lighting, shared Front View / Back View controls, and physical
button-shaped macro hotspots. Preserve every existing front asset and geometry.

- X20: straight rear, four controls; X20 Pro: user's rear reference, six controls.
- X05: straight rear, no programmable buttons; X05 Pro: rear with a slight pitch
  exposing its two mini shoulder buttons; X10 and D10: straight rear, two controls.
- Store normalized polygon geometry beside each rear image. Fit artwork and
  hotspots in the same image plane so resizing cannot separate their coordinates.
- Buttons page rear hotspots route into that player's macro editor; Macros page
  rear hotspots select the matching local slot. Hover/focus follow real outlines.
- Keep all preview models session-only; introduce no native operations or writes.
- Verify types/build, focused tests, and isolated headless normal/compact previews.
  No screen access, hardware access, desktop launch, or publishing.
