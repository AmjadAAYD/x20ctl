# X20ctl 4.1.0 Preview 1

Windows x64 preview with the four-player workspace, seven controller models, shared Studio navigation, revised controller artwork and control highlights, compact macro editing, and an integrated guided controller scanner.

## Download
Extract the Windows ZIP and run x20ctl.exe. The built-in guided scanner runs inside the same executable; no separate scanner download is needed. Microsoft WebView2 Runtime is required. The executable is unsigned.

## Compatibility
- X20 retains its existing configuration backend.
- X15 input is experimental and read-only. Model identity, proportional trigger travel, and physical operation still require owner testing. Configuration writes, independent M1/M2 detection, RGB and vibration-strength control are not enabled for X15.
- X20 Pro remains a preview; X05, X05 Pro, X10 and D10 retain previews and Scan now / Scan later prompts. Preview artwork does not establish hardware support.

## Research scanner
Guided input, trigger, vibration observations, metadata and optional trace collection are available. No photo collection or RGB probing. Captures stay local until consent and report review. Automatic website submission remains unavailable until the updated X20ADMIN receiver is deployed; local ZIP export and manual sharing remain available.

## Verification and limits
Focused Python checks (248 passing), TypeScript and frontend build, isolated headless flow checks, and packaged internal-worker checks passed. These checks do not establish native-window acceptance or live-controller behavior. Native GUI acceptance was not rerun because screen access is prohibited. This is a prerelease; 4.0.1 remains the stable release. No Linux binary is included.
