# Release 2.0.0: x20ctl Gamepad Configurator Suite

**Tag:** `v2.0.0`  
**Date:** 2026-09-17  
**Author:** AmjadAAYD  
**Target:** Production / Cross-Platform Web & Desktop  

---

## Overview

**x20ctl 2.0.0** is the major milestone upgrade of the open-source configuration and diagnostic suite for the **EasySMX X20 / X20 Pro** and controllers using the **KeyLinker** protocol.

This release completely modernizes the architecture from a legacy Python desktop tool into a fast, cross-platform, zero-install Web & Desktop application built with **React 18**, **TypeScript**, **Tailwind CSS**, **Vite**, the **Web Gamepad API**, and native **Web Bluetooth GATT** protocol integration.

---

## Changelog

### 🚀 Everything That Is New

- **Zero-Install Web App**: Connect and configure directly from your browser (Chrome, Edge, Opera, Brave) without installing Python, pip packages, C++ compilers, or vendor drivers.
- **Interactive SVG Vector Controller Diagram**: High-precision vector controller visualizer (`src/components/ControllerDiagram.tsx`) featuring real-time button glow on physical inputs, animated pulse rings for selected controls, click-to-remap on any button, and theme skinning (Matte Obsidian & Pro Ice White).
- **Interactive Response Curve & Deadzone Studio**: Draggable dual-point Hermite Bézier curve editors (`src/components/pages/CurvesPage.tsx`) for left/right analog sticks and left/right triggers, complete with inner and outer deadzone sliders, sensitivity gears, and real-time stick crosshairs.
- **Piano-Roll Macro Sequencer**: Visual timeline macro arranger (`src/components/PianoRollModal.tsx`) across all 4 rear buttons (M1, M2, M3, M4). Supports millisecond-precision hold and gap duration tags (snapped to 5 ms hardware intervals), looping intervals, and an 8-way directional stick compass snap dial.
- **Live Hardware Macro Recording**: Record live gameplay combos directly from the controller into any macro slot with real-time timing capture.
- **Hardware Input Diagnostics & Polling Rate Meter**: Live input verification suite (`src/components/pages/TesterPage.tsx`) featuring full button matrix state, analog trigger pressure bars, circular stick coordinate deflection trails with drift detection, and high-frequency polling rate counter (up to 1000 Hz).
- **Multi-Profile Management**: Create, duplicate, rename, delete, and switch between customized controller profiles with persistent local storage and instant JSON profile export/import (`src/data/defaultProfiles.ts`).
- **Interactive Theme Engine**: Four custom color palettes (`src/types/theme.ts`) including **Matte Obsidian** (cyber ember accents), **Midnight Slate**, **Cyberpunk Neon**, and **Retro Ivory**.
- **Introductory Hardware Device Scanner**: BLE and 2.4 GHz dongle discovery interface (`src/components/IntroScanner.tsx`) guiding users through connection pairing and quick setup.
- **Web Bluetooth GATT Protocol Engine**: Full TypeScript protocol serialization and CRC-8 packet builder (`src/protocol/keylinker.ts`) implementing the KeyLinker BLE GATT service (`0000ffe0-0000-1000-8000-00805f9b34fb`).
- **Real-Time Haptic Actuation**: In-browser dual-rumble motor actuation via Gamepad API vibration actuators with live strength testing (0–100%).

### 🧹 Everything That Is Removed

- **Removed Python 3.10+ Runtime Requirement**: Eliminated the need to install or configure Python virtual environments, pip packages (`bleak`, `pyqt5`), or native build toolchains.
- **Removed Windows-Only `XInput1_4.dll` Dependency**: Input testing and configuration no longer relies on native Windows DLLs, unlocking full native cross-platform support across macOS, Linux, ChromeOS, and Windows.
- **Removed Heavy PyQt5 Windowing Overhead**: Replaced legacy Qt widget styling with modern Tailwind CSS and hardware-accelerated SVG animations, eliminating window resizing lag and UI freeze issues.
- **Removed Deprecated CLI & Ad-hoc Scripts**: Removed fragmented Python scripts (`app.py`, `x20ctl.bat`, `pyproject.toml`, `x20ctl.spec`, `tools/ble_enum.py`, etc.) in favor of a clean, unified TypeScript codebase with full type safety.
- **Removed Modal Dialog Blockers**: Replaced blocking native modal dialogs with smooth, non-intrusive in-app slide-overs and notification toasts.

### 🛠️ Everything That Is Fixed

- **Fixed Platform Lock-in**: Full cross-platform compatibility across macOS, Linux, ChromeOS, and Windows via standard Web APIs.
- **Fixed UI Thread Locking During Device Scans**: Scanning no longer freezes the application interface; device enumeration runs asynchronously via Web Bluetooth `navigator.bluetooth.requestDevice`.
- **Fixed Accessibility & SVG Title Tag Rendering**: Fixed non-standard SVG `title` attribute errors across the controller diagram by embedding semantic `<title>` elements for accessibility and screen reader support.
- **Fixed TypeScript Remapping Types**: Resolved strict type mismatches in key remap dictionaries and dynamic button state mappings.
- **Fixed Intermittent Trigger Query Timeouts**: Hardened protocol state handling to gracefully default unread trigger or stick curves rather than crashing the workspace with uncaught runtime errors.
- **Fixed Text Contrast & Spacing**: Standardized spacing, high-contrast typography, and WCAG AA-compliant colors across all tabs and panels.
