# x20ctl 2.0.0

Status: released September 18, 2026.

A real Windows desktop app with the new controller-studio design, backed by the restored native Python engine.

## Added

- Bundled local React interface in a native Windows window.
- Button studio, dark/light controller illustration, response curves, macro piano roll and explicit draft/apply workflow.
- Native BLE discovery/configuration and separate XInput testing/recording.
- Per-category validation and read-back checks; visible partial failures.
- Native JSON setup storage, import/export, legacy profile migration and deletion.
- Single-instance behavior, close-to-tray and optional GitHub update checks.
- Full self-contained x64 executable with a Microsoft WebView2 fallback.
- Automated native-window acceptance and genuine screenshots from the executable.

## Fixed

- Restored the protocol engine, CLI, tests, tools and Windows CI removed by the prototype rewrite.
- Fixed skipped adjacent recorded inputs and invented pauses.
- Removed zero-duration pause entries from macro capacity usage.
- Treat missing remap replies and incomplete macro replies as unknown/errors, not default or empty settings.
- Preserve curve flags and native units; keep stored response points on the visual curve.
- Fixed desktop bridge startup race, unsupported remap destinations, incorrect macro capacity and invalid timing choices.
- Preserve partial legacy profile scope and protect malformed saved data from overwrite.
- Corrected README, changelog, security and troubleshooting claims.

## Removed

- Browser-only configuration and the unused invented TypeScript protocol.
- Separate Tkinter mock backend, fabricated recordings and fake telemetry.
- AI-generated marketing screenshots, invented checksums and false provenance/attestation claims.
- Unsupported cross-platform/PWA and X05 support implications.

## Download

Use **x20ctl.exe** on Windows 10/11 x64. No Python, Node or browser tab is required. The full package is large because it includes an offline rendering-runtime fallback. Startup unpacks the application. The app is unsigned; verify it against the attached `SHA256SUMS.txt`.

## Validation and limitations

Final validation results and screenshot provenance are recorded in `docs/desktop-validation.md`. The release executable passed all 16 packaged native-window checks and has Windows file/product version 2.0.0. No fresh physical-controller write or macro replay was performed. The restored protocol regression suite and simulated transport tests do not replace physical acceptance. Battery intermediate levels and firmware interpolation remain explicitly uncertain. X05 is unsupported. Version 1.2.0 remains available for rollback.

Thanks to @SpookyyQ for the X05 investigation. This is an independent interoperability project, not a manufacturer-endorsed application.
