# x20ctl 2.0.1

Fixes saving controller setups when firmware reports empty macro slots as neutral zero-duration entries. This issue was reproduced with a live Xpert2 controller running firmware 9.01. Real initial delays and normal macro steps are preserved.

Hardware verification passed: configuration connection, complete settings reads, a timer change from 10 to 11 minutes with read-back, restoration to 10 minutes, and an unchanged final settings snapshot. The connected desktop UI successfully saved the real controller setup after the fix. XInput captured real left-stick and button changes. Macro playback, right-stick motion and trigger motion were not verified.

Download **x20ctl.exe** for Windows 10/11 x64. The full executable includes Python, the interface and a WebView2 fallback. No Python or Node installation is needed. The EXE remains unsigned. Verify it against the attached `SHA256SUMS.txt`.

Version 2.0.0 remains available; 2.0.1 is the recommended update for the setup-saving fix. Full changes and testing scope are in `CHANGELOG.md` and `docs/desktop-validation.md`.
