# X20ctl 4.0.1

This update fixes the vibration strength track so its orange fill follows the selected level. Support X20ctl is visible below the X20 studio navigation, and the optional Ko-fi button is left aligned in its dialog. The unfinished X20 Pro discovery footer link has been removed from the Controllers page.

The X20 Pro backend remains read-only. This release does not claim new controller compatibility or hardware verification.

Download `x20ctl-4.0.1-win-x64.zip`, extract it, and keep `x20ctl.exe` beside `x20ctl-scanner.exe`. The app uses the installed Microsoft WebView2 Runtime. The executables are unsigned; verify the archive against `SHA256SUMS.txt` before running it.
