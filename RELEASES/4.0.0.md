# X20ctl 4.0.0

This release replaces the desktop interface with a fixed navy layout, controller imagery, a left navigation rail, and a compact status header. The button page adds a keyboard and pointer preview for visual testing; it does not send preview input to a controller. Theme Studio and its color editor, and the X20 Pro rear illustration/view, are intentionally removed. X20 Pro configuration remains read-only.

For a selected Bluetooth LE device, the separate scanner collects standard GATT diagnostics and writes them locally. X20ctl verifies the scanner's release-pinned SHA-256, validates and previews the report, and sends the ZIP to X20ADMIN only after explicit consent. An upload failure keeps the same ZIP and submission UUID for retry. The scanner does not upload data. USB/HID descriptors, input captures, and compatibility with additional hardware have not been verified or claimed.

The optional Support X20ctl dialog opens the official Ko-fi page in the default browser. Supporting the project does not change application features.

The Windows download is `x20ctl-4.0.0-win-x64.zip`. Extract it and keep `x20ctl.exe` and `x20ctl-scanner.exe` together. The paired build verifies the scanner after packaging. The app uses the installed Microsoft WebView2 Runtime; the executables remain unsigned. Verify the downloaded archive against the accompanying `SHA256SUMS.txt` before running it.

The Windows file version and the version displayed in the app both report 4.0.0.
