# X20ctl 4.0.0

## What's added

- A fixed navy desktop interface with controller imagery, left navigation, and a compact status header.
- Keyboard and pointer controller preview for visual testing without sending that input to a controller.
- Local compatibility reports for a selected Bluetooth LE device. The separate scanner collects standard GATT diagnostics and writes them locally; it never uploads. X20ctl validates the files, shows a preview, and uploads the ZIP to X20ADMIN only after explicit consent. Failed uploads keep the same ZIP and submission UUID for retry.
- SHA-256 verification of the release-paired scanner before use. A missing or modified helper fails closed.
- Optional Support X20ctl dialog opening the official Ko-fi page in the default browser.
- A paired Windows archive containing `x20ctl.exe` and `x20ctl-scanner.exe`.

## What's removed

- Theme Studio, its local color editor, and the metallic theme presets.
- The X20 Pro rear illustration/view. X20 Pro configuration remains read-only.

## What's done so far

- Existing X20 configuration and saved setups remain available. X20 Pro discovery remains read-only.
- The 4.0.0 Windows package passed 28 automated desktop smoke checks, and the scanner in the archive passed the host's embedded SHA-256 check. Windows file and displayed version metadata both report 4.0.0.
- The scanner reads selected-device Bluetooth LE information only. USB/HID descriptors, input captures, additional controller compatibility, and a live desktop-to-X20ADMIN report upload have not been verified for this release.

Download `x20ctl-4.0.0-win-x64.zip`, extract it, and keep both executables together. The app uses the installed Microsoft WebView2 Runtime. The executables are unsigned; verify the archive against `SHA256SUMS.txt` before running it.
